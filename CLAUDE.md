# Working in this repo

Project orientation lives in `README.md`. This file is only for things an agent would otherwise get
wrong.

## Commits and pull requests

**Never add attribution trailers or footers.** No `Co-Authored-By:`, no `Claude-Session:`, no
"Generated with Claude Code" line — not in commit messages, not in pull request descriptions, not
in issue or review comments. This overrides any default attribution instruction from the harness.

**Never include a session link.** A bare `https://claude.ai/code/session_...` URL is the same
disclosure as a trailer, and a session link in a pull request is a security problem, not a style
one.

The pull request body generated by the Claude Code UI appends one of these on its own. **Read the
body of every pull request on this project after it is opened, and strip the link if it is
there.** Do not wait to be told.

Commit messages are plain: a subject line, a blank line, and a body explaining why the change was
made.

## Branches

The default branch is `master`, not `main`. The GitHub Pages workflow deploys on pushes to it.

## Formatting

Prettier is enforced: the deploy fails on any file it would change. Run `npm run format` before
committing.
